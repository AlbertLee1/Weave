## Codebase Patterns
- Frontend ↔ Backend gap-coverage PRD：先 grep 既有 `// US-XXX` 注释；本期前 35 story 中有相当部分已经在 v1/v2/v3 parity 轮次落地（如 US-001 ↔ US-147 Property admin），写代码前先确认现状再追加。
- 写操作 React Query 失效模式：每个写 hook 调 `qc.invalidateQueries({ queryKey: ['<entity>', ontology, ...] })`，同时连带失效父集合（如 Property mutation 失效 properties + objectTypes 双 key）。
- `web/vite.config.ts` 同时承载 vitest 配置；Playwright BDD spec 若放 `web/tests/**` 需加入 vitest exclude，否则会被当成 vitest spec 触发 "Playwright Test did not expect test.describe()" 错误。
- 前端代码默认 browser-only，禁止用 `Buffer` fallback；`btoa`/`atob` 在 jsdom + 现代浏览器都已就位。
- `SavedObjectSet` 类型现在强制要求 `versions` + `activeVersionId` 字段，老测试 fixture 需补齐。
