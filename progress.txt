### Key Foundry Facts (do not re-research)
- Wire format: __rid/__primaryKey/__apiName (double underscore) for standard endpoints; $rid for preview multi-type endpoints
- Action path param: {action} (not {actionType}) for execution endpoints; {actionType} for metadata
- Apply options: mode = VALIDATE_ONLY | VALIDATE_AND_EXECUTE; returnEdits = ALL | ALL_V2_WITH_DELETIONS | NONE
- Batch options: returnEdits = ALL | NONE only (2 values, no mode field)
- No separate validateAction endpoint — use apply with VALIDATE_ONLY
- No applyAsync / executeAsync — all sync
- No link write REST — must go through Action rules
- Search/LoadObjectSet select field is REQUIRED
- ListOntologies has NO pagination
- ObjectSet has 15 definition variants (Weave has 9)
- Interface uses dual path: /interfaceTypes/ for metadata, /interfaces/ for data queries
- Attachment is global: /api/v2/ontologies/attachments/... (no {ontology})

### Gotchas
- pkg/oss/handlers_link_crud.go has zero consumers (frontend/SDK/CLI) — safe to delete
- main.go inline aggregate closure duplicates objectset handler — delete it
- Auth middleware must be MiddlewareWithAPIKeys for api-key bearer to work
- TimeSeries path params inconsistent: {property} vs {propertyName} — match Foundry exactly

- When adding sub-resource endpoints under interfaceTypes (e.g. outgoingLinkTypes): register specific routes BEFORE the wildcard {interfaceType} route in routes.go so chi doesn't swallow them
- When deleting frontend admin code: remove api/admin.ts, hooks/useAdminMutations.ts, components/admin/ directory, admin routes from App.tsx, Admin nav from Sidebar.tsx, and any admin imports in DashboardPage/hooks

- When deleting a route: remove from RegisterRoutes, delete handler+service files, update Service interface, clean mock impls in all test files (including pkg/mcp/tools_test.go), remove OpenAPI paths from both yaml files
- OSS Handler setter pattern: SetAggregation — always register the route in RegisterRoutes, return "XxxNotConfigured" error when deps are nil. Wire setters from NewFullRouter before RegisterRoutes call. (SetHistoryRepo/SetBroadcast removed in US-006)

- ApplyRequest.Options is *ApplyOptions (pointer, omitempty) — nil means use defaults
- Handler resolves options with defaults before calling executor; executor is options-unaware
- VALIDATE_ONLY uses Prepare() only — no CommitBatch, no Publish
- returnEdits=NONE omits edits from response envelope (edits still generated and published internally)
- Old deprecated fields are rejected with 400 + DeprecatedField error code
- Test helpers: setupRouter(), newTestActionType(), mustJSON(), fakePublisher{} in actions_test.go / batch_test.go
- Executor-level tests (batch_test.go) test ApplyBatchAtomic/BestEffort directly; handler-level tests go through HTTP

- ApplyResult fields have `json:"-"` tags — internal only, not serialized to wire
- Frontend ActionApplyResponse has edits as ActionResults (counts), not individual edit objects

- ObjectSet Executor optional deps go through Setters (SetInterfaceResolver, SetOmsRepo etc.) — keeps NewExecutor signature stable and old tests working. Nil dep → execute-time error with a clear "not configured" message.
- Frontend ObjectSetNode (UI builder) ≠ wire-format ObjectSetDefinition. nodeToDefinition is total over all ObjectSetNode variants; definitionToNode is partial — new wire variants that the UI composer doesn't model should throw in definitionToNode with an "unsupported in composer" message rather than add stub Node types.
- When adding a new Definition field in pkg/oss/objectset/definition.go: always tag with omitempty and pick a sensible zero value (empty slice / "" / nil pointer) so existing JSON wire shapes round-trip unchanged.
- Foundry apply variants (apply / applyWithOverrides / applyBatch) all share the same SyncApplyActionResponseV2 / BatchApplyActionResponseV2 envelope + countEdits helper — when adding another variant, construct an ApplyRequest and forward to executor.Apply, do not duplicate the Prepare/Apply/returnEdits control flow beyond what handlers.go already does.
- Action handler tests use pub.batches (slice of all published EditBatch) — not a lastBatch field. funnel.Edit has Properties map, no After/Before.
- pkg/attachment is the Foundry attachment blob layer: BlobStore interface + LocalStore filesystem backend (`<uuid>.blob` + `<uuid>.meta.json` sidecar). RID shape is `ri.attachments.main.attachment.{uuid}` (new "attachments" service, separate from "ontology"). validateRID() rejects path traversal before any FS access. Unlinked uploads expire via StartCleanupLoop(ctx, interval, maxAge) — wired with 10m/1h in main.go as of US-033.
- Global attachment HTTP handlers (no {ontology}) live at pkg/attachment/handlers.go — keeps the blob layer self-contained. ServerDeps.AttachmentStore (attachment.BlobStore) carries the dep; handler is mounted inside the auth group in NewFullRouter.
- Object-path attachment read endpoints (/objects/{type}/{pk}/attachments/{property}...) live in pkg/oss/handlers_attachment_property.go instead of pkg/attachment, because they need svc.GetObject to load the object first. oss.Handler gets the BlobStore via a new SetAttachmentStore setter (same pattern as SetAggregation / SetOmsRepo). extractAttachmentRID handles both single-string and []interface{} property values (Bleve returns arrays as []interface{}, never []string).
- AttachmentProperty chi route ordering: /{property}/content must come BEFORE /{property}/{attachmentRid}, and /{property}/{attachmentRid}/content must come BEFORE /{property}/{attachmentRid} — longest-static-segment-first, otherwise chi's trie matches "content" as a wildcard value.
- When adding new routes to NewFullRouter, you MUST also wire the corresponding deps on newContractTestRouter in cmd/server/contract_test.go — otherwise TestContract_NoOrphanedSpecPaths fails because the new OpenAPI path entries have no matching chi route in the contract router.
- Phase 4 storage packages (timeseries) pattern: ship both MemoryStore (default single-machine backend + test harness) and PGStore (migration-backed, wired when deps.PGPool != nil). main.go selects based on PGPool presence. Tests use MemoryStore to keep `go test ./...` offline.
- Foundry TimeSeriesProperty streamPoints endpoint accepts optional ?format=JSON|ARROW. Our single-machine scope only emits JSON — ARROW returns 400 UnsupportedFormat (the endpoint is still callable so Foundry clients that default to JSON work unchanged).
- pkg/cipher.Decryptor is the swap point for CipherTextProperty decryption. Default AESGCMDecryptor uses envelope encryption with wire format "v1:<base64url(nonce||sealed)>". Swapping in a KMS-backed implementation only requires providing another Decryptor via SetCipherDecryptor — no handler changes. WEAVE_CIPHER_KEY env var (32+ bytes) enables the default at boot; unset = degraded mode with CipherDecryptorNotConfigured 500.
