- DLQ 路径有完整的辅助函数：`BuildDLQSubject(suffix)` / `IsDLQSubject(s)` / `OriginalSubjectFromDLQ(s)` / `ReplayDLQMessage(env, publish)` / `DiscardDLQMessage(env)`。replay 路径反推 `OriginalSubject` 重投到 live stream，operator UI / CLI 可直接调；discard 是 audit-only marker（JetStream MaxAge 自己驱逐 DLQ entry）。
