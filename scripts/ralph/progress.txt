## Codebase Patterns
- LinkType admin handlers use **tri-state pointer** for partial PUT fields (nil = preserve, &value = set). Mirror this for any new optional field; bare value collapses "omit" and "clear" into one (see UpdateLinkTypeRequest.PropagateMarkings & TypeClasses).
- LinkType wire format uses `omitempty` so the JSON shape stays backwards compatible — emit new fields from ToWireJSON only when non-zero.
- PostgreSQL TEXT[] columns: pgx v5 scans into `[]string` directly. SELECT with `COALESCE(col, '{}'::text[])` keeps nil rows safe; INSERT pass `[]string{}` (not nil) to avoid pgx encoding gotchas.
- Frontend Vertex pure helpers live under `web/src/features/vertex/<feature>/` with `<helper>.ts` + `<helper>.test.ts` siblings (Vitest, no React).
- Frontend admin UI for OMS resources lives in `web/src/components/admin/*.tsx`; co-located `__tests__/*.test.tsx` use a `installFetch(state)` stub pattern to mock the v2 REST endpoints.
- `cmd/server/embed.go` requires `cmd/server/web/dist/*` to exist before `go build ./...` works — keep a placeholder file when running Go tests without first building the frontend.
- Migration numbering: VTX stream uses 000200+. Add a `down.sql` even if it just drops the column.
- **JSON Schema validation**: use `github.com/santhosh-tekuri/jsonschema/v5` (already in go.mod). Embed the schema with `//go:embed`, register via `compiler.AddResource(memURL, strings.NewReader(...))`, set `compiler.Draft = jsonschema.Draft7`, then `Compile(memURL)`. Pattern is established in `pkg/actions/parameter_schema.go`.
- **OMS reference checks** belong on a tiny purpose-built interface (e.g. `ReferenceLookup{ GetObjectType, GetLinkType }`) that `*oms.PGRepository` satisfies structurally. Don't import `oms.Repository` (huge surface) into a downstream package — the focused interface keeps tests cheap.
- Pre-existing baseline failures unrelated to your story: `cmd/server.TestContract_AllRoutesDocumented` (missing OpenAPI entry for `/timeseries/{property}` from VTX-030) + perf gates `pkg/cellsec.TestUS376_PerfGate_*` and `pkg/security.TestRLSEvaluator_PerformanceGate`. Don't try to fix these in your iteration — verify with `git stash` if in doubt.
- `prd.json` and `progress.txt` at repo root are symlinks to `scripts/ralph/{prd.json,progress.txt}` — Edit through the symlink fails ("Refusing to write through symlink"); always edit the real path.
- **New vertex routes**: every chi route under `/api/vertex/...` must be either in `api/openapi.yaml` or in `cmd/server/contract_test.go::undocumentedRouteAllowList`, otherwise `TestContract_AllRoutesDocumented` fails. VTX-009 routes ride the allow-list until the OpenAPI schemas land.

- **Learnings for future iterations:**
  - Pattern: When you need a pure JSON-path mutator, sort segments via `regexp.MustCompile("^([^\\[\\]]+)(\\[(\\d+)\\])?$")` and bracket-indexing only at *terminal* spot of each dotted segment. Keeps the parser shallow (no full pointer grammar) while supporting the `layers[0].filter.objectRid` form the Vertex UI already serializes.
  - Pattern: For mutate-in-place over decoded JSON, walk `map[string]any` + `[]any` and refuse to auto-create missing containers — a template snapshot whose path doesn't resolve is almost certainly an author bug that should surface as 400, not be silently extended.
  - Pattern: Parameter binding by *leaf segment* (last `.`-segment of the path) gives a clean UX (`{"objectRid":"…"}`) at the cost of forbidding two parameterized fields that share a leaf name. The whole-path form is reserved for a future enhancement; until then the leaf form matches the BDD verbatim.
  - Pattern: When mirroring a TS planner on the backend (here: `web/.../parameterizedSearchAround.ts`), keep the call descriptor shape byte-identical (`functionRid` / `objectRid` / `params`) so the FE consumes the response without a translation layer.
  - Gotcha: chi `r.Post("/.../templates/{rid}/instantiate", …)` lives on the same handler struct as `/graphs/{rid}/…`. Don't try to spin up a separate templates handler — the existing handler already has the `templates TemplateStore` dependency and shares the same `chi.URLParam(r, "rid")` parameter name without collision (each route gets its own `{rid}` scope).
  - Gotcha: `httputil.ReadJSON` on an empty body returns `io.EOF`, which surfaces as 400 InvalidJSON. The instantiate handler guards with `if r.ContentLength != 0` so callers can omit the body entirely (degenerate "no params" instantiate) — useful when the only point of instantiate is the searchAroundCalls plan.
  - Useful: Adding any new chi route under `/api/vertex/...` requires either an `api/openapi.yaml` entry OR an entry in `cmd/server/contract_test.go::undocumentedRouteAllowList`; otherwise `TestContract_AllRoutesDocumented` will fail (or, more confusingly, won't list YOUR route in the error since it's only listed when it lacks both).
