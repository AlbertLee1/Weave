- i18n bootstrap: prod entry `main.tsx` does `import './i18n'` for the side-effect init; vitest `src/test/setup.ts` does NOT. Any component that calls `useTranslation()` must side-effect-import `'../i18n'` itself, otherwise `t(key)` returns the raw key in component tests that don't transitively reach the i18n module. Pattern: `import { useTranslation } from 'react-i18next'; import '../i18n';`.
- i18next plural collision: passing `{ count: N }` to `t()` makes i18next route to `_one`/`_other` plural variants; if you only define a single non-suffixed key, lookup fails and the raw key leaks into the UI. Use a different variable name (e.g. `{ num }`) for non-plural counters.
- Existing vertex lint baseline has 2 errors (`react-refresh/only-export-components` on MapOpenInVertexButton, `react-hooks/set-state-in-effect` on ScenarioDebugDrawer); both pre-date this stream. Verify no NEW lint errors before commit by stashing and rerunning `npx eslint src/vertex/`.
