## Codebase Patterns
- LinkType admin handlers use **tri-state pointer** for partial PUT fields (nil = preserve, &value = set). Mirror this for any new optional field; bare value collapses "omit" and "clear" into one (see UpdateLinkTypeRequest.PropagateMarkings & TypeClasses).
- LinkType wire format uses `omitempty` so the JSON shape stays backwards compatible — emit new fields from ToWireJSON only when non-zero.
- PostgreSQL TEXT[] columns: pgx v5 scans into `[]string` directly. SELECT with `COALESCE(col, '{}'::text[])` keeps nil rows safe; INSERT pass `[]string{}` (not nil) to avoid pgx encoding gotchas.
- Frontend Vertex pure helpers live under `web/src/features/vertex/<feature>/` with `<helper>.ts` + `<helper>.test.ts` siblings (Vitest, no React).
- Frontend admin UI for OMS resources lives in `web/src/components/admin/*.tsx`; co-located `__tests__/*.test.tsx` use a `installFetch(state)` stub pattern to mock the v2 REST endpoints.
- `cmd/server/embed.go` requires `cmd/server/web/dist/*` to exist before `go build ./...` works — keep a placeholder file when running Go tests without first building the frontend.
- Migration numbering: VTX stream uses 000200+. Add a `down.sql` even if it just drops the column.
- **JSON Schema validation**: use `github.com/santhosh-tekuri/jsonschema/v5` (already in go.mod). Embed the schema with `//go:embed`, register via `compiler.AddResource(memURL, strings.NewReader(...))`, set `compiler.Draft = jsonschema.Draft7`, then `Compile(memURL)`. Pattern is established in `pkg/actions/parameter_schema.go`.
- **OMS reference checks** belong on a tiny purpose-built interface (e.g. `ReferenceLookup{ GetObjectType, GetLinkType }`) that `*oms.PGRepository` satisfies structurally. Don't import `oms.Repository` (huge surface) into a downstream package — the focused interface keeps tests cheap.
- Pre-existing baseline failures unrelated to your story: `cmd/server.TestContract_AllRoutesDocumented` (missing OpenAPI entry for `/timeseries/{property}` from VTX-030) + perf gates `pkg/cellsec.TestUS376_PerfGate_*` and `pkg/security.TestRLSEvaluator_PerformanceGate`. Don't try to fix these in your iteration — verify with `git stash` if in doubt.
- `prd.json` and `progress.txt` at repo root are symlinks to `scripts/ralph/{prd.json,progress.txt}` — Edit through the symlink fails ("Refusing to write through symlink"); always edit the real path.
