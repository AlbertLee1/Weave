## Codebase Patterns
- MCP server dispatch lives in `pkg/mcp/server.go`; method-specific resource behavior lives in `pkg/mcp/resources.go`.
- MCP initialize capabilities are locked by both package tests and `scripts/ci/ci_workflow_bdd_test.go` string checks, so docs/status tests must be updated with server changes.
- MCP resource subscription should validate subscribes against the live resource catalog, but unsubscribe should remain idempotent so clients can clean up after resource deletion.
- MCP `resources/list` accepts optional `pageSize` and opaque `cursor`; cursors resume after the previous page's last URI, so the resource catalog must stay URI-sorted before pagination.
- `cmd/weave-mcp` bridge options live in `http_bridge.go`; env-to-option wiring lives in `main.go`, and `scripts/ci/ci_workflow_bdd_test.go` has string guards that must follow new bridge env contracts.
- Frontend component tests use Vitest + React Testing Library under `web/src/components/**/__tests__`.
- React i18n uses a singleton initialized at `web/src/i18n/index.ts`; component copy should prefer `useTranslation()`.
- Count-summary UI copy in admin pages should format `0` with plural nouns and reserve singular nouns for exactly `1`.
