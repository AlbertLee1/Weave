## Codebase Patterns
- For Weave browser/UI regressions, Hermes browser verification is final truth; Claude/Playwright self-checks are necessary but not sufficient.
- Dashboard aggregate stats should hoist per-ontology fetches with `useQueries` and share React Query cache keys with per-card hooks.
- Frontend BDD tests conventionally stub `fetch` directly with `vi.stubGlobal('fetch', ...)` and regex URL matching; do not default to MSW for new focused tests unless the local suite already uses it.
- AI News dogfood fixture lives in `dogfood-output/ainews-records-20260517.json` / `.csv` and contains 103 records over 6 delivery dates.
- BrowserPage search currently exercises the `WhereClause` path, not the simple backend `query` parameter path; tests should assert the exact request body sent by `searchObjects`/BrowserPage.
- OMS handlers grow narrow `Set*` hooks (e.g. `SetIndexBootstrapper`) for cross-package wiring; the concrete adapter lives in cmd/server so pkg/oms never imports pkg/index. Mirror this pattern for any future capability that needs index/funnel knowledge.
- Stream ingest must verify the target Bleve index exists BEFORE publishing to NATS; the consumer's "index not found" error fires too late and the 200 response has already gone out.
