## Codebase Patterns
- Browser page BDD tests commonly use React Testing Library plus MSW and mocked metadata hooks; see `web/src/components/browser/__tests__/BrowserPage.search.bdd.test.tsx` for request-contract assertions.
- Browser route state is reset by keying `BrowserPageContent` on `ontology/objectType`; keep changes scoped inside Browser controls unless route identity changes are part of the story.
- SearchBar now treats BrowserPage `searchText` as the committed source of truth while maintaining a local draft so ad hoc typing still waits for Enter except when clearing the input.
- Browser bulk selection intentionally persists across pagination within a query, but should be cleared when a handler replaces the query context (text search, filters, facets, or saved search).
- Browser live mode uses WebSocket first and only flips to the documented SSE fallback after WebSocket reports `reconnecting` and a temporary ObjectSet RID is available; ObjectSet provisioning errors should be held separately from transport status so the header can explain fallback readiness failures.
