## Codebase Patterns
- Migrations 序号已用到 000104；新增使用 000105+。一对 `*.up.sql` / `*.down.sql`，up 必须用 `IF NOT EXISTS` / `DO $$ ... IF NOT EXISTS ... END$$` 保证幂等，down 必须按 FK 依赖反向 DROP。
- 集成测试用 `//go:build integration` + `testutil.StartPGContainer(t)`（pgvector/pgvector:pg16，每 case 独立容器，~1.2s 启动）。运行：`go test -tags integration ./... -run TestX -v`。需要 Docker。
- 测试命名遵循 PRD tddConvention：`Test{Feature}_Given_{State}_When_{Action}_Then_{Outcome}`。
- 校验 column / index 存在：`information_schema.columns` / `pg_indexes`（`indexdef ILIKE '%(col_a, col_b)%'`）。
- Module path: `github.com/liyang/weave`，迁移文件路径由 `testutil.MigrationsDir()` 自动向上搜索 8 层定位 `migrations/`。
- Vertex 命名前缀：RID 形如 `ri.vertex.{realm}.{resourceType}.{uuid}`；与现有 `ri.ontology.*` 区分但共用 PG schema。
- Repo 风格遵循 pkg/oms.Repository：小接口、ctx-first、sentinel error（`ErrXxxNotFound` / `ErrXxxImmutable`）让调用方可 `errors.Is`。PG 实现写 `var _ Repo = (*PGRepo)(nil)` 编译期断言接口满足。
- 应用层并发写 + 状态翻转：`SELECT ... FOR UPDATE` + tx 阻塞并行 AppendEdit / Freeze，避免 immutable 翻转后还能追加 edit。pgx.BeginTx + defer Rollback 是标准模式。
- pgx 的 JSONB 写法：`json.RawMessage` 或 `[]byte` 直传，pgx 会自动处理 jsonb 类型；空切片传 nil interface 防止某些版本 panic。`NULLIF($n, '')` 把空字符串映射为 NULL，匹配 schema 的 nullable text 列。
