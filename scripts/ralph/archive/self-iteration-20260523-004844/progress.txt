## Selected Story
- RSI-001 Security policy writes reject ambiguous JSON bodies.
- Rationale: row policies, column masks, and cell masks are OSv2 security-control write surfaces. They still decode request bodies with raw `json.NewDecoder(r.Body).Decode`, so a concatenated JSON body can apply the first policy/update while silently ignoring trailing data. This is the same API-boundary class fixed in the previous Ralph cycle for permission requests and tenant quota writes.
